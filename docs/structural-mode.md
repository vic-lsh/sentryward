# Structural mode

`--structural-term TERM --structural-report OUT` (`cpp/src/value_analysis/structural.cpp`) checks
the wiring of a binding term against one launch's memory-eliminated value IR, before the
scalar-fold lowering. The term (schema `sentryward.structural-term/v2`) is input data generated by
the caller from a kernel row's declaration.

## What a match states, and what it does not

A match states, per output element: the element's value reaches exactly the term's operand
elements (leaves); a primitive atom's stored value is that one operation on its operands, up to
commutativity and the named conversions; an opaque consumer reaches its producers only through
their stored values (factorization); every opaque argument's role holds (below).

**A match is never evidence of op identity.** Which op an opaque atom computes, and its numerics,
rest on the trusted kernel row (the caller's contract), not on this check. Roles exist only to tell
equal-shaped operands of that trusted op apart (`silu_mul(gate, up)` versus `silu_mul(up, gate)`).
They are facts about dataflow paths, not semantic dependence: a path through a select's condition,
or through an operation whose result cancels the operand (`x - x`, `x * (y - y)`), still counts as
a path. A use of part of an operand's bits does not (partial operands, below).

## Roles

Over the complete dataflow of the output element (index values, conversion sources, replaced loads
and operands; no cut ends a path). The sources of an input argument are its initial-memory loads;
of a body argument, the values its producer's stored output elements hold, by value identity.

- `through_transcendental`: every element of the argument reaches the output by some path that
  passes ex2, lg2, sin, cos or tanh strictly above it.
- `avoids_transcendental`: every element reaches the output, none by such a path.
- `addend`, `multiplicand`: input arguments only (`structural.cpp`, `RoleKind`).

## Refusals that keep paths honest

- **Dead edges** (`dead_operand`): an operand that the launch does not fix reaches a value only
  through an operation that a constant decides without it: a product (mul, mad, an fma's product)
  with a zero factor, and with zero, or with all ones, a logical shift by at least the width, bfe
  of length zero, a select with a fixed condition. Such an edge is not a path and not a leaf, so
  `a * b + 0 * ex2(a)` is refused rather than credited with a path from `a` through ex2 (IEEE
  `0 * inf` is NaN, so the edge is not dropped either). A select whose condition the launch fixes
  is normally resolved to its chosen operand first (scalar specialization), so only the chosen
  branch is followed.
- **Partial stored reads** (`partial_stored_read`): a load that reads part of a stored value's bits
  (a reinterpreted or reassembled read). Per-byte dependencies are not tracked, so crediting all
  the value's leaves could hide a missing dependency (a pack of `a`'s low half and `b`'s high half,
  read back as the low half, depends on `a` only). A piece that is all of a stored value's bits is
  exact. Role reachability refuses any read reassembled from stored values (`reassembled_read`).
- **Partial operands** (`partial_operand`): an edge is full when the operation reads every bit its
  operand may vary in. Per value, `bits()` keeps the bits that may vary (a superset) and the fixed
  value of the others, through constants, bit operations with fixed controls, shifts by fixed
  amounts, integer extensions and truncations and same-width bitcasts; any other result varies in
  every bit. Partial, by the bits each reads: and/or/xor/lop3 per bit (for every value of the other
  operands' varying bits, so a mask that is itself data is undecided), shl/shr (shr.s past the
  width reads the sign), bfe, bfi, prmt (default mode), shf, integer truncation (cvt, a mov.b32
  unpack), integer products (below), quotients and remainders (full only for `x / 1`; any other,
  including by a data value, is undecided), float abs (no sign),
  copysign (one operand's sign, the other's magnitude), slct's integer selector (its sign), a
  component of an operation's matrix result; a control the launch does not fix (mask, amount,
  position, selector, table) makes the use undecided, so partial. Integer products (mul.lo,
  mad.lo; fixed or data factors): flipping factor bit i changes the low half by `o * 2^i`, zero mod
  2^w exactly when the other factor o has at least w - i trailing zeros, so with t = o's trailing
  zeros the product reads the factor's low w - t bits; t is decided only when o's low bits are
  fixed zero up to a fixed one, else the use is undecided (`x * (x << 1)` = 2x^2 ignores x's bit
  31). Wide products read every bit when some bit of o is fixed one; high halves are undecided.
  Roundings, decided exactly (numerics inside the atom): (1) `and` with a fixed mask on a float's
  own bits (a chain of same-width bitcasts of an f16, bf16, f32 or f64 value) that clears only a
  contiguous run of its low bits and keeps the sign and every exponent bit: an and keeps each bit
  in place, so the result is that float rounded toward zero in its own format; (2) a narrowing
  store: an opaque node's element in a bf16 field (2 bytes, store format bf16 or none) whose stored
  value, less same-width bitcasts and one integer truncation to 16 bits, is a shift right by 16 of
  an f32's own bits (`__float_as_uint(v) >> 16` stored as u16, k_combine_pos_store_trunc); its 16
  stored bits are the f32's bf16 encoding rounded toward zero, as `cvt.rz.bf16.f32` stores, so the
  element's checks (leaves, factorization, roles) start from the f32. A shift whose kept bits are
  used any other way (as an f32, `>> 17`, into an f16 field) is partial. A reload of the value from
  memory under an integer type is not recognized as a float's bits (partial). A partial edge counts for claims
  that no path exists (avoids_transcendental, a multiplicand's bypass, an addend's non-addend
  paths) and never for claims that one does: an output's leaves must all be reached by full paths
  (`fullLeaves`), so must a factorization's cut elements and an unstored producer's operands, and
  an argument of a role must reach the output (through a transcendental, for that role) by a full
  path, as a factor of a multiplicand or along addend edges. `reload(p) & 0xffff` is refused; nvcc's
  `expf` (`shl.b32` of the low 9 bits of a rounding result, whose source also reaches the output in
  full) is not. A full-width reassembly of partial uses (`{lo, hi}` unpacked and repacked) is
  refused too: each use is partial. Counting partial edges for absence claims is sound because those
  traversals follow every edge (full or partial) of the complete dataflow: a dead operand (a
  product with a literal zero, a mask or shift that clears every bit) is refused, not dropped; a
  select whose condition the launch fixes has only its chosen operand as an edge; a narrowing
  store skips only its shift and truncation, whose one other operand is the fixed amount 16.
- **Undecided steps** (`unsupported`): reads at data-dependent positions, unresolved loads,
  undetermined values, thread selectors the launch does not decide, operation kinds not listed.

## Value identity

`ident()`: node result and instance, pointer properties, indices and conversion chain, each level
resolved. Cut values, producer bindings, stored primitive operands, body sources and memos compare
values by it. Controls: `tests/structural_cases/ir/index_controls.cpp` (pairs that differ only in
one index).

- `tests/test_structural_native.py`: native controls (`SENTRYWARD_PTX_NATIVE`; the IR-level
